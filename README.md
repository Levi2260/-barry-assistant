# Barry Assistant Web Starter

Mobile-friendly dark futuristic web-app shell with five modes, local chat history, local notes, and optional browser speech-to-text.

Important: this starter is an interface prototype, not a connected AI assistant yet. It saves typed messages locally and clearly indicates that the AI connection is not configured. Notes and chats do not sync across devices. Voice input is browser speech-to-text only; spoken replies are not implemented.

Host these files on an HTTPS static web host. Never put API keys in app.js or other browser files. Add a server-side AI endpoint later, with the key stored as a server secret.

On iPhone, open the hosted site in Safari → Share → Add to Home Screen.
